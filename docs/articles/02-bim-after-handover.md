# BIM 完工後就沒用了嗎？從竣工交付到營運維護的數位資產

**摘要**：不會。BIM 模型如果在完工後封存，工程階段累積的資料就浪費了。把模型延伸到驗收、交付、物業與設備管理，它就成為建築長期可用的數位資產。

## 簡單回答

BIM 的價值不該停在設計與施工。Aiii VBIM 的做法是：模型不在完工後封存，而是持續進入驗收、交付、物業與設備管理，讓設計 → 施工 → 驗收 → 營運 → 資產管理每一個階段都能被追蹤、被理解、被延續。

## 為什麼完工後的模型常被閒置？

原有建築流程把設計、圖說、施工、影像、設備與營運拆成不同系統，資訊分散在業主、建築師、工程顧問、營造、監造驗收與物業端。完工交付時，資料常常只剩一疊紙本或檔案，營運團隊很難接手使用。

## 怎麼讓模型在營運階段繼續有用

1. **把工程資訊拉回同一個平台**：圖說版本、RFI、送審簽核與竣工資料，和 BIM 模型放在一起管理（PMIS）。
2. **把設備放進空間**：設備台帳、感測器、維修紀錄對應到模型中的位置，報修與保養都能從空間找到設備。
3. **整合影像與文件**：影像、文件、數位孿生與上鏈紀錄串在一起，從現場到資料追溯都可視、可追蹤、可延續。

## 營運階段能得到什麼

當人、物、空間、設備、管線、工程清單與進度全部數位化，系統不只告訴你現在發生什麼，更能提前看見接下來會發生什麼。建築因此成為具有感知、分析與管理能力的智慧資產。
