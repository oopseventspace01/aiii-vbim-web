## 寫作原則

- 內容**只取自網站已核准文案**（每篇開頭標出資料來源）；沒有根據的事實一律標 `[TBD: 說明]`，請業主補上或刪掉那一題。
- 結構：標題是問題 → 摘要與「簡單回答」先給答案 → 每段一個小標（單獨被 AI 引用也看得懂）→ 表格 → 常見問題 → 延伸閱讀連到官網。
- 封面：Codex 產生的 AI 示意圖（`covers/`），**沒有文字與數字**；放進後台時圖片說明寫「…示意」。

## 審稿後的流程

1. 業主與 Andy 在這些檔案上修改，或回覆「OK」「修改：…」。
2. Claude 把定稿放進後台「最新消息」，分類選「知識專欄」，保留「待審稿」勾選；業主在後台最後確認後取消勾選並發布。
