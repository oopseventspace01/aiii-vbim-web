## 寫作原則

- 內容**只取自網站已核准文案**（每篇開頭標出資料來源）；沒有根據的事實一律標 `[TBD: 說明]`，請業主補上或刪掉那一題。
- 結構：標題是問題 → 摘要與「簡單回答」先給答案 → 每段一個小標（單獨被 AI 引用也看得懂）→ 表格 → 常見問題 → 延伸閱讀連到官網。
- 封面：Codex 產生的 AI 示意圖（`covers/`），**沒有文字與數字**；放進後台時圖片說明寫「…示意」。

## 匯入後台

- 指令：`npm run import:articles`（只新增後台沒有的文章；`npm run import:articles -- --force` 會用這裡的版本覆蓋草稿，不動已發布的版本）。
- 存成草稿，網站看不到；業主在後台「最新消息」找到文章 → 修改 `[TBD]` → 取消「待審稿」→ 按「發布」，約 1 分鐘後出現在網站。
- 後台內文沒有表格，Markdown 表格會轉成條列。
- **之後以後台為準**：業主在後台改過後，這裡的 Markdown 不會自動同步，不要再用 `--force` 覆蓋。
