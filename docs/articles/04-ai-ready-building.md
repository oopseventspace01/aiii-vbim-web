# 什麼是 AI-Ready Building？建築師在設計階段要預留哪些 AI 基礎建設

**摘要**：AI-Ready Building 是在設計階段就把 AI 規劃進建築，而不是完工後才加裝。建築師與顧問在規劃初期就把 AI 需要的運算、網路、電力、散熱與機房寫進圖面與規範。

## 簡單回答

不是完工後再加裝 AI，而是在規劃初期，就把 AI、能源、空調、影像、AIoT、網路、UPS、機房與維護需求寫進圖面與規範。這樣的建築稱為 AI-Ready Building。

## 為什麼要在設計階段就規劃？

完工後才加裝 AI，常會遇到機房空間不夠、電力與散熱不足、網路與管線要重新拉的問題。若在設計階段就把 AI 運算、記憶體、儲存、網路與散熱一起規劃進去，就能形成可 Design-In 的 AI-Ready Building Solution。

## 設計階段要預留哪些項目

| 項目          | 說明                                         |
| ------------- | -------------------------------------------- |
| AI 運算與儲存 | 地端 AI 伺服器、記憶體、儲存設備的空間與規格 |
| 網路          | 攝影機、感測器到機房的網路與管道             |
| 電力與 UPS    | AI 設備的供電與不斷電需求                    |
| 空調與散熱    | 機房與設備的散熱規劃                         |
| 影像與 AIoT   | 攝影機、感測器的位置與數量                   |
| 維護          | 日後維修、更換設備的動線與空間               |
