# BIM、BMS、數位孿生有什麼不同？一張表看懂建築資料的三個層次

**摘要**：BIM 管設計與工程資料，BMS／EMS 管設備與能源的即時監控，數位孿生則把空間、設備、能源與營運資料接在一起。三者不是互相取代，而是建築資料的不同層次。

## 簡單回答

- **BIM（建築資訊模型）**：強項是設計與工程資料，但模型常在完工後封存，營運數據與控制不足。
- **BMS／EMS（建築與能源管理系統）**：強項是設備與能源監控，但缺少 3D 空間與工程生命週期的資訊。
- **數位孿生**：把空間、設備、能源、影像與營運資料放進同一個架構，讓建築從設計、施工、驗收、交付到營運都能被追蹤、被理解、被延續。

## 一張表看懂

| 類型           | 強項           | 常見限制                 | Aiii VBIM 的做法       |
| -------------- | -------------- | ------------------------ | ---------------------- |
| BIM／CDE       | 設計與工程資料 | 營運數據與控制不足       | 工程資料延伸至營運     |
| BMS／EMS       | 設備與能源     | 缺少 3D 與工程生命週期   | BIM＋資產＋能源        |

## BIM：模型不該在完工後封存

傳統流程把設計、圖說、施工、影像、設備與營運拆成不同系統。BIM 在設計與施工階段很有用，但完工後模型往往就被封存。Aiii VBIM 的模型不在完工後封存，而是持續進入驗收、交付、物業與設備管理，成為長期可用的數位資產。

## BMS／EMS：看得到設備，看不到空間

BMS／EMS 擅長監控空調、電力等設備，但異常發生時，很難知道它對應到哪個空間、哪段管線、哪張維修紀錄。把 BIM 的空間關係和設備、能源資料放在一起，就能從空間直接追到對應的設備、感測器與維修紀錄。

## 數位孿生：把三者接起來，還能預見接下來

當人、物、空間、設備、管線、工程清單與進度全部數位化，系統不只告訴你「現在發生什麼」，更能提前看見「接下來會發生什麼」。這也是傳統 BIM 管模型、Aiii VBIM 管整個真實世界的差別。

## 常見問題

**Q：已經有 BMS，還需要數位孿生嗎？**
A：BMS 負責設備監控，數位孿生把設備放回空間與工程生命週期中，兩者是互補的。可以先從一個明確痛點（例如能源或空調）切入，驗證成效後再擴展。
