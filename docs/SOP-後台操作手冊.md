# 後台操作手冊（SPEC 13-1）

給業主團隊（Nick、Andy）自己更新網站內容用，不需要工程師。
欄位名稱都和後台畫面上的文字一致。

---

## 0. 登入

1. 打開 **https://aiiivbim.com/admin**（網站上線前請直接用 **https://aiii-vbim.sanity.studio**）
2. 用被邀請的 Google 帳號（或 Email）登入。只有被邀請的成員才看得到內容；新增成員見 `設定說明.md`。
3. 左側「內容」就是所有可以改的東西：

| 側欄     | 用來改什麼                                                                       |
| -------- | -------------------------------------------------------------------------------- |
| 全站設定 | 首頁標語、背書條、公司資訊、LINE、App 下載連結、頁尾標語、首頁消息則數、全站 SEO |
| 最新消息 | 新聞、活動、黑客松、媒體報導、產品發表                                           |
| 案例     | 導入案例（預設不公開）                                                           |
| 認證課程 | 認證學院的課程與梯次                                                             |
| 夥伴     | 生態夥伴與 Logo（預設不顯示）                                                    |
| 場域     | 五大領域的資料                                                                   |
| 一般頁   | 隱私權政策等單頁                                                                 |

每一類都分「繁體中文」「English」「全部語言」三個清單。

## 1. 共通規則（每一種內容都一樣）

### 1-1 待審稿：新文件預設不能發布

新文件的「**待審稿**」預設是勾選的，這時按「發布」會出現：

> 此文件為「待審稿」。請審稿者確認內容後取消勾選，才能發布。

審稿者確認以下 4 件事後，**取消勾選「待審稿」→ 按右下角「Publish（發布）」**：

1. 文字沒有錯字
2. 數字與客戶名稱已取得公開同意（不確定就先不要放）
3. 每張圖片都有「圖片說明（替代文字）」
4. 中英文版本內容一致（有英文版時）

### 1-2 草稿與發布

- 改到一半會自動存成**草稿**，網站上看不到。按「Publish」才會出現在網站。
- 網站上線並設定好自動重建後，**發布後約 3 分鐘內**網站會更新（SPEC 8 的目標；實際時間上線後測一次記在這裡：`[TBD: 實測時間]`）。

### 1-3 圖片

- 上傳後一定要填「**圖片說明（替代文字）**」：用一句話描述圖片內容，沒填會無法發布。
- 建議尺寸：封面圖橫式、寬 1600px 以上；Logo 用去背 PNG 或 SVG。

### 1-4 英文版

- 打開中文文件 → 右上角「**Translations**」→ 選「English」→ 會建立一份對應的英文文件，填好英文內容再審稿、發布。
- 沒有英文版時，英文網站會顯示中文內容並提示「English version coming soon」，不會出現空白頁。

### 1-5 網址代稱

- 「網址代稱」是網址最後一段，例如 `aiii-vbim-launch`。按「**Generate**」會由標題自動產生（英文小寫與連字號）。中英文版可以用同一個。

## 2. 發一則最新消息

側欄「最新消息」→「繁體中文」→ 右上角「**＋**」（或 Create new）

| 欄位             | 怎麼填                                                            |
| ---------------- | ----------------------------------------------------------------- |
| 標題             | 70 字以內                                                         |
| 網址代稱         | 按「Generate」                                                    |
| 分類             | 新聞／活動／黑客松／媒體報導／產品發表                            |
| 封面圖           | 上傳並填圖片說明                                                  |
| 發布時間         | 選日期時間。設成未來的時間，到時間後網站重新建置時才會出現        |
| 顯示日期（選填） | 想顯示不同於發布時間的日期時才填                                  |
| 摘要             | 120 字以內，用在列表與搜尋結果                                    |
| 內文             | 文章內容（可插入圖片、YouTube、按鈕、連結）                       |
| 置頂精選         | 勾選後顯示在「最新消息」頁最上方的大卡片                          |
| SEO 設定（選填） | 搜尋結果標題（60 字內）、描述（160 字內）、分享預覽圖（1200×630） |

**依分類不同：**

- **媒體報導**：填「媒體名稱」（例如「經濟日報」）與「原始報導連結」，**內文不用填**，網站會直接連到原始報導。
- **活動**：填「活動日期」「活動地點」（兩個都填，Google 搜尋才可能顯示活動資訊）、「報名連結」。
- **產品發表**：可以不寫內文，改在「站內連結」填要連到的頁面，例如 `/edge-ai`。

→ 審稿（見 1-1）→ 發布。
→ 首頁「產品發表」「媒體報導」區會自動顯示最新幾則（則數在「全站設定 → 首頁最新消息顯示則數」，3～5）。

## 3. 上傳一個案例

側欄「案例」→「繁體中文」→「＋」

| 欄位         | 怎麼填                                                             |
| ------------ | ------------------------------------------------------------------ |
| 公開顯示     | **預設不公開**。取得客戶書面同意後才勾選；沒勾的話網站完全不會顯示 |
| 案名         | 例如「某醫學中心空調節能」                                         |
| 所屬場域     | 選醫院、商場、工廠、辦公或能源                                     |
| 客戶顯示名稱 | 可以匿名，例如「北部某醫學中心」                                   |
| 痛點         | 客戶原本遇到的問題                                                 |
| 導入模組     | 用了哪些模組                                                       |
| 成果數字     | 「指標」＋「數值」，**只放客戶同意公開的數字**                     |
| 照片         | 每張都要填圖片說明                                                 |

→ 審稿 → 發布。勾了「公開顯示」的案例才會出現在案例頁。

## 4. 新增一個夥伴 Logo

側欄「夥伴」→「繁體中文」→「＋」

| 欄位            | 怎麼填                                                                   |
| --------------- | ------------------------------------------------------------------------ |
| Logo 已取得授權 | **預設未授權**。取得夥伴書面同意使用 Logo 後才勾選；沒勾的話網站不會顯示 |
| 夥伴名稱        | 公司名稱                                                                 |
| Logo            | 上傳去背 PNG／SVG，填圖片說明（例如「○○公司 Logo」）                     |
| 夥伴類型        | 設備製造商／工程技術商／能源公司／Cybersecurity                          |
| 合作方式        | Technology／Solution／SI／Certified／POC Partner                         |
| 顯示在首頁      | 勾選後也會出現在首頁的 Logo 牆（仍須先勾「Logo 已取得授權」）            |

→ 發布。

> ⚠️ CLAUDE.md 規定網站不可出現的公司名稱（WSP、群聯 Phison、長庚醫院、台塑集團、台泥、三菱重工、大金、Panasonic、東元）請不要新增；網站的自動檢查也會擋下。

## 5. 修改首頁標語與 SEO 標題

側欄「全站設定」→「全站設定（繁體中文）」（英文版選「English」）

| 欄位                            | 用途                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| 首頁主標語                      | 首頁最大的那行字                                                                             |
| 首頁副標、首頁內文              | 標語下方的文字                                                                               |
| 60 秒影片網址                   | 影片完成前請留空，網站會顯示封面圖與「影片製作中」                                           |
| 背書項目                        | 首頁 Hero 下方 4 格，每格「標題」＋「說明」                                                  |
| 戰情室截圖                      | 上傳後首頁戰情室區會換成真實截圖（沒上傳時顯示「示意畫面」）                                 |
| 公司名稱、地址、電話、Email     | 頁尾與聯絡頁                                                                                 |
| LINE 官方帳號連結、QR Code      | 聯絡頁與頁尾                                                                                 |
| App Store／Google Play 下載連結 | 頁尾                                                                                         |
| 首頁最新消息顯示則數            | 3～5                                                                                         |
| 頁尾標語                        | 頁尾                                                                                         |
| 全站預設 SEO                    | **建議填**：首頁的「搜尋結果標題」與「描述」（目前中英文首頁都用預設的「Aiii VBIM OS 2.0」） |

→ 全站設定沒有「待審稿」，改完直接按「Publish」。

## 6. 認證課程（開課時）

側欄「認證課程」→「＋」：課程名稱、級別（基礎／進階／專家）、課程簡介、課程內容，以及「梯次」（開始日期、名額、費用、報名狀態、報名方式）。
報名方式選「外部連結」時要填「外部報名網址」。
→ 審稿 → 發布。有課程後，認證學院頁會出現「課程與梯次」區。

---

## 7. 改錯了怎麼辦

- **還沒發布**：右上角「⋯」→「Discard changes（捨棄變更）」。
- **已經發布**：右上角「⋯」→「**History（歷史紀錄）**」→ 選之前的版本 →「Restore（還原）」→ 再按「Publish」。
- **不想讓它出現在網站**：「⋯」→「Unpublish（取消發布）」，內容還在，只是網站看不到。
